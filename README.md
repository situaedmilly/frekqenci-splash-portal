
# 🌀 Frekqenci Splash Portal – GODMODE Edition

This is the official splash portal for the metaphysical platform Frekqenci.
Built using React + Vite + TailwindCSS + react-three-fiber.

## 🔥 Features
- Sacred geometry + 3D orbit controls
- Ambient trap music
- Lottie particle field
- Social Frequency Gates (Instagram, TikTok, Snap, Facebook)
- Fully responsive and deployable

## 🚀 Run Locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## 🌍 Deploy via Netlify, Vercel or GitHub Pages

1. Push this repo to GitHub
2. Connect to Netlify or Vercel
3. Set build = `npm run build`, output = `dist`
